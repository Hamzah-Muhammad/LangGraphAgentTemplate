# Write a report

1. Open with the answer in one or two sentences. No preamble.
2. Then the evidence, grouped by theme, one short paragraph or table per theme.
3. Use a table when comparing three or more items on the same attributes.
4. Name the source of each non-obvious fact (tool name or document).
5. End with open questions or caveats only if they change what the reader should do.

Keep sentences short. Plain words. No filler closing line.
